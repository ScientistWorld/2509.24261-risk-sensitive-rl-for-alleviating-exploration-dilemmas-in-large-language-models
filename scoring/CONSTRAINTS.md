# Scientist Constraints

## Problem

The 100-action reward landscape and initial policy in `data/bandit_spec.py`
must remain fixed. Changing the global peak, local peak, number of arms, or
initial logits changes the exploration problem rather than improving a method.

## Budget

Use the same interaction budget and update batch size as the benchmark entry
being compared: 120,000 sampled actions, grouped into batches of 16.
The default reported score averages ten independent seeds: 0 through 9.

## Evaluation

Scores must be produced by `scripts/evaluate.sh` from saved artifacts. The
evaluator must not be modified to special-case a method's outputs.

## Compliance Checklist

- [ ] `data/bandit_spec.py` reward and initialization functions are unchanged
- [ ] The submitted run uses 120,000 sampled actions and batch size 16
- [ ] The submitted run uses the default seeds 0 through 9, or documents a different seed set
- [ ] `scoring/scores.json` was generated by `scripts/evaluate.sh`
