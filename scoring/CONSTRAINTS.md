# Scientist Constraints

## Problem

Instances (including their hidden reward scales), the hidden per-group
reward offsets, the initial policy, the interaction budget (7,500 groups of
16), the learning rate (0.1), the softmax policy-gradient update, the
advantage cap (|A| <= 8) and the episode counts are fixed by the evaluators
in `eval/`.
A method cannot change them: it only returns advantages for the groups the
evaluator samples. `data/bandit_instances.py` is a visible copy of the
instance generators for development. Editing it does not change scoring.

## Interface

A method is an agent file `method/<name>.py` (or `baseline/<name>.py`) that
implements the protocol in `data/agent_protocol.py`: `--list` prints its
variant names, and `--serve NAME` answers one episode on stdin/stdout. Each
episode runs in a fresh process. Write logs to stderr only.

Every top-level, non-underscore `*.py` file in `method/` and `baseline/` is
scored. A file that fails to list or serve is scored as a failed method.

## Evaluation

Scores are produced only by `scripts/evaluate*.sh`. Advantages must be finite
and within the cap in every group; otherwise the method is scored as failed
on every metric of every experiment.

## Compliance Checklist

- [ ] The method is an agent file speaking the protocol; it does not read or
      write anything under `eval/` or `scoring/`.
- [ ] Advantages are computed from the rewards the evaluator sends (and the
      method's own state), not from knowledge of the instance generator's
      seeds or of the evaluator's internals.
- [ ] No file in `eval/` was modified.
- [ ] `scoring/scores.json` was generated by `scripts/evaluate.sh`.
